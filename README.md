# ProInstall And Diesel Solutions

Landing page para una empresa dedicada a la programación electrónica de maquinaria pesada y tractocamiones.

## Incluye

- Hero de conversión con propuesta de valor y CTA.
- Servicios de programación de ECU, emisiones y diagnóstico.
- Tabla editable de motores y precios de referencia.
- Proceso de trabajo y sección para historias de casos reales.
- Especificaciones para las fotografías pendientes.
- Formulario de contacto preparado para conectar con Francisco.

## Pendientes de contenido

- Logotipo original en SVG/PNG transparente.
- Teléfono/WhatsApp y correo de Francisco.
- Fotografías propias: 1200 × 900 px mínimo, JPG o WEBP, 3–5 por caso.
- Lista final de motores, precios y autorizaciones para publicar historias.
